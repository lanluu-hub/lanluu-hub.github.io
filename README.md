# Lan Luu — Portfolio

Personal portfolio highlighting my software development experience,
selected projects, technical skills, and education.

Portfolio v2 rebuilds my original static HTML/CSS/JavaScript site using
React and TypeScript.

## Website

https://lanluu-hub.github.io/

Portfolio v2 is under development on `feat/react-rebuild`.
The existing portfolio remains live until the rebuild is released.

## Stack

- React and TypeScript
- Vite
- React Router
- Bootstrap and React Bootstrap
- ESLint
- GitHub Pages

## Run locally

Use Node.js 24 and npm.

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Validation

```bash
npm run lint
npm run build
```

The build checks TypeScript and generates the production site in `dist/`.

To preview that build:

```bash
npm run preview
```

## Project structure

- `src/components/` — shared navigation, footer, project cards, and experience entries
- `src/pages/` — homepage, project details, and not-found page
- `src/data/` — typed project, experience, and skills content
- `src/styles/` — shared styles and visual identity
- `public/` — resume PDF and static assets

## Routing

The site uses HashRouter for static hosting on GitHub Pages.

Example project route:

`/#/projects/idx-property-search`

Homepage section navigation uses a query parameter:

`/#/?section=selected-work`

## Deployment

The GitHub Actions workflow validates pull requests targeting `main`.

Pushes to `main` run lint and build, then publish `dist/` to GitHub Pages.
The repository's Pages source must be configured as GitHub Actions.

Build output is generated by the workflow and is not committed.

## Development approach

This project is an incremental React and TypeScript learning project.
Content is separated from presentation through typed data and reusable
components.
